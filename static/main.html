Downloaded files:

Downloading Files

Download Video and Audio from single youtube videos or whole playlists.

Once your download is complete, the file will appear in the downloads iframe on the webpage.

Desktop Instructions

To download a single file on desktop:

Hover your mouse over the file link inside the downloads iframe

Right click the link (or double tap your mouse pad)

Click "Save Link As..."

Choose where you'd like to save the file

The file will then download directly to your computer.

Mobile Instructions

To download a single file on mobile:

Press and hold the file link

Wait for the options menu to appear

Tap the download option (such as "Download Link" or "Save Link" depending on your browser)

The file will then download to your device.

Downloading Everything at Once

If you prefer, you can use the "Download All" button to download the entire downloads folder as a ZIP archive.
